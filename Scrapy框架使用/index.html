学了scrapy好几次了，每次学会了长时间不用就忘记了，本文简单记录一下scrapy的使用方法，方便后续快速回顾。

Scrapy框架使用

环境搭建

使用miniconda创建一个python3.13的虚拟环境（也可以使用其它python环境），直接使用 pip install scrapy 完成安装，当前下载的scrapy版本为2.16.0 。

创建一个新的爬虫

安装完成之后，打开命令行输入 scrapy startproject test_spider （test_spider是爬虫项目的名字）就会在当前目录下生成一个爬虫项目的文件夹。其中：

  • scrapy.cfg：通过scrapyd进行部署时的配置文件
  • test_spider/spiders/：爬虫代码文件夹，一个爬虫项目能有多个爬虫
  • test_spider/items.py：定义爬取内容存储的数据结构
  • test_spider/middlewares.py：定义scrapy中间件
  • test_spider/pipelines：定义数据处理的管道代码（将爬取到的数据依次交给管道的每个环节）
  • test_spider/settings.py：爬虫的配置文件（限速、中间件优先级、管道优先级等）

目前test_spider/spiders/文件夹是空的，需要在当前爬虫项目目录下执行 scrapy genspider bbc_spider 'www.bbc.com' （bbc_spider是爬虫的名称，www.bbc.com是要爬取的主域名），执行之后test_spider/spiders目录下会出现bbc_spider.py文件，这是这个爬虫的入口文件。其中：

  • name ：这个爬虫的名称，主要用于后面管理爬虫
  • allowed_domains：允许的域名列表，和创建爬虫时指定的域名相同，后面在爬虫运行时，如果要爬取的url的domain不在这个列表里，就会被scrapy拒绝
  • start_urls：要抓取的初始url列表，爬虫运行时会先获取这个列表里的url进行抓取，可以修改这个列表以从指定的页面开始爬取
  • def parse：当scrapy完成页面的抓取后，会回调这个函数，response为网页返回的内容

运行爬虫

我要抓取的第一个页面是 bbc的世界杯新闻，因此我将start_urls里的url修改为 https://www.bbc.com/sport/football/world-cup，并在parse函数里打印response的text属性，即网页的html文本（具体有哪些属性可以查询官方文档，或者自己断点调试）。

在爬虫项目目录下运行 scrapy crawl bbc_spider 可以启动这个爬虫，可以看到打印的日志。 打印的日志中显示因为robots协议，抓取这个网页被禁止了。scrapy是默认支持robots协议的，想要继续抓取的话，需要在settings里面关闭robots协议支持。

在settings.py中将遵守robots协议修改为False（国内网站请严格遵守robots协议），再次运行爬虫就可以看到打印的网页html内容。

断点调试

目前虽然能运行爬虫，但是无法进行断点调试。在爬虫项目目录下新建python文件并写入爬虫启动代码，打上断点后即可进行调试。代码的作用为将当前工作目录切换到爬虫项目目录，将爬虫项目目录添加到Python的搜索路径中，运行 scrapy crawl bbc_spider 命令。

需要选择Python环境为创建的虚拟环境。

正则表达式

调用函数

Python用于查找的正则表达式一般使用如下三个方式调用：

  • re.match 尝试从字符串的起始位置匹配一个模式，写的正则表达式必须满足字符串开头的匹配
  • re.search 查找符合条件的字符串，只能找到一个
  • re.findall 查找多个符合条件的字符串

用一段代码例子，说明这三种调用方式的区别：

flag

上述正则表达式函数的调用参数一般为：1、正则表达式 2、要匹配的字符串 3、flag

flag标识正则表达式的过程中使用的模式，多个模式可以使用 | 拼接，如 re.I | re.S

  • re.I 忽略大小写匹配
  • re.S 使 . 匹配包括换行符在内的所有字符
  • re.M 多行模式：^ 和 $ 匹配每行的开头和结尾，而不仅仅是整个字符串的开头和结尾

表达式

  • \w 匹配字符 \W 匹配非字符
  • \d 匹配数字 \D 匹配非数字
  • \s 匹配空格 \S 匹配非空格
  • ^ 以xxx开头 \$ 以xxx结尾
  • [abcdA-Z] 匹配 [] 中的一个字符，可以写 A-Z a-z 0-9 批量匹配，如果 [] 中以 ^ 表示不能取 [] 中的任一字符
  • () 用于在匹配的字符串中取值，如 re.search 和 re.match 的group函数，或者 re.findall 返回的list都是 () 里的值
  • . 表示匹配任意字符 ? 表示匹配前面的表达式0个或者1个 + 表示匹配前面的表达式1个以上 * 表示匹配前面表达式任意个
  • (hello|world|me) 匹配这三个字符串中的一个
  • {m,n} 表示匹配前面的表达式m到n次
  • 非贪婪模式：在表示匹配数量的表达式后面接上 ? 表示尽可能少的匹配前面的数量，通常使用 .*?
    • ab)ab) 如果使用 ab.*\) 或匹配到完整的字符串， 使用 ab.*?\) 之后匹配到前面的 ab)

部分 含义
^(int|void|char\\*) 开头必须是 int、void 或 char*

提取url列表

回到本文的例子，使用正则表达式从网页中提取新闻url列表。由于页面内容比较多，正则表达式通过表达式去模糊匹配内容速度会非常慢，只能使用下面的方式：根据url中关键字进行匹配。

XPath

XPath 分析并存储html标签结构，通过专用的语法从分析的标签结构中提取数据，用法如下：

  • .get() 和 .getall() 分别返回匹配的第一个字符串和匹配到的所有字符串列表
//tag 选取所有指定标签，无视层级
/tag 从根节点选取
.//tag 当前节点下的所有指定标签
//tag[@attr="value"] 按属性筛选
//tag/text() 提取文本内容
//tag/@attr 提取属性值
//tag[position()] //tag[last()] 按位置筛选
//div[contains(@class, "active")] 包含某 class（class 可能有多个值）
response.xpath('//div[@class="item" and @data-id="123"]') 多条件组合
response.xpath('//span[@class="price"]/parent::div') 父元素
response.xpath('//h2/following-sibling::p') 兄弟元素

发起新的请求

scrapy爬虫在刚创建的时候，start_urls里只有一个url，即使可以再手工往里面添加一些，但对于一个网站爬虫是远远不够的，因此需要在代码中动态创建新的请求。

  • 使用 yield scrapy.Request 动态发起新的请求
    • url 参数表示请求的url，由于从主页提取的url列表只有路径没有域名，因此需要使用 response.urljoin 将url路径和域名进行拼接，也可以使用urllib中的parse函数 urllib.parse.urljoin(response.url, cur_url) ，这两个函数可以自动识别要拼接的url路径包不包含域名，只有不包含时才进行拼接
    • callback 函数用于指定请求返回后由哪个函数进行处理

数据传递

爬虫在抓取时可能会在多个页面抓取数据，但是数据最终会存储在一条记录里，比如先从新闻列表页面抓取新闻的标题、摘要，再到新闻详情页面抓取新闻的详情。这就涉及到数据如何在scapy的请求间进行传递。在请求间传递数据，有两种方式：

  • 在 scrapy.Request 中使用meta参数， scrapy.Request(url, callback, meta={"data": "123"}) ，在callback函数中处理请求时，通过 response.meta 获取传递的数据

  • 在 scrapy.Request 中使用cb_kwargs参数， scrapy.Request(url, callback, cb_kwargs={"data": "123"}) ，修改callback函数的参数列表，增加 cb_kwargs 传递的参数名，scrapy会自动将传递的数据映射到callback的参数中，这样可以避免参数名使用错误

items定义和使用

在爬虫项目目录下的items.py文件中（也可以新建一个文件），新建一个Item类（需要继承于 scrapy.Item），在类中定义好要保存数据的字段。

定义好item格式之后，在爬虫代码要保存数据的回调函数中实例化item并赋值，之后通过yield关键字将实例化的item交给scrapy框架处理。

item pipeline

scrapy框架会通过item pipeline对yield关键字抛出的item进行处理。我们可以在item pipeline中处理数据的保存。下面在爬虫项目目录下的pipelines.py中（也可以新建文件）定义3个item pipeline，分别用于数据处理、保存数据到文件、保存数据到数据库。根据代码可以观察到，item pipeline的类有以下关键的函数：

  1. process_item，负责处理scrapy框架传递过来的item对象，可以对item内容进行修改和保存，如果函数return item，下一个item pipeline类就可以获取到数据，否则下一个item pipeline类拿不到数据
  2. open_spider，在爬虫启动时执行的代码，通常用于连接数据库、创建文件
  3. close_spider，在爬虫结束时执行的代码，通常用于关闭数据库、关闭文件
  4. from_crawler，在scrapy框架启动时运行，用于给item pipeline类的构造函数传递参数，如果不实现这个函数，scrapy框架会调用item pipeline类的无参构造函数

图片下载

新闻列表中存在图片，想在爬取标题的时候也同时把图片下载到本地。

首先使用xpath表达式从页面中提取每个新闻的图片url， //div[@data-testid="alaska"]//a[contains(@href, "article")]//div[@data-testid="card-media"]//img[last()]/@src ，再修改相关代码在item中增加image_urls这个属性，此属性为list类型，属性名不能改变（scrapy中ImagePipeline会处理这个字段）。

scrapy提供了用于图片下载的pipeline，在pipelines.py中新建一个pipeline继承ImagesPipeline并重写item_completed方法（使用此pipeline需要先 pip install Pillow ，否则不会生效）。 注意在爬虫入口代码的allowed_domains列表中需要加上图片url所属的域名，否则图片下载请求会被过滤掉。

在settings.py中启用pipeline并设置图片保存目录，这个pipeline应该在数据库保存的pipeline前面执行，这样存储到数据库中的数据就包含了下载到本地的图片路径：

其它配置

本小节介绍一下settings.py中的一些配置

cookie禁用

scrapy.Request发送请求时，默认是带cookie并且会保存服务器返回的cookie，可以在settings.py中不启用cookie。

自动限速

算法规则：

  1. 爬虫始终以 AUTOTHROTTLE_START_DELAY 的延迟开始
  2. 收到响应后，目标延迟 = latency / AUTOTHROTTLE_TARGET_CONCURRENCY
  3. 下次请求的延迟 = (前次延迟 + 目标延迟) / 2（平滑调整）
  4. 非 200 响应不会降低延迟（服务器出错时自动减速）
  5. 延迟不会低于 DOWNLOAD_DELAY，也不会高于 AUTOTHROTTLE_MAX_DELAY

自定义settings

一个爬虫项目可以通过 scrapy genspider 创建多个爬虫代码，可能需要不同的爬虫使用不同的配置，此时只需要在定义爬虫类中定义custom_settings就可以了

暂停和重启

scrapy启动和重启时指定保存数据的目录，可以让爬虫恢复到上一次运行的状态（需要按ctrl+c键停止爬虫，而不是强行停止）。

  • 启动、恢复爬虫时在命令行指定保存数据的目录
  • 或者可以在settings.py中配置
