binwalk解包只解出部分文件系统

2026-04-13
|
  • IoT-security
hits

使用binwalk对某固件进行解包时发现只能解出部分文件系统，这里记录解决方法。

背景说明

目标固件大小100MB左右，使用binwalk解包之后得到的文件系统大小为20MB，越想越觉得不对劲：

  1. 固件本身一般是压缩过的，压缩后的大小都有100MB，解压之后即使有一些驱动文件也不可能才20MB。
  2. 与业务相关的二进制和Web程序一个没找到。因为能解出来部分文件系统，也不太可能有加密。

解决办法

和同事在沟通的过程中发现他电脑上binwalk解包出来的文件系统比我解出来的还要少，突然意识到可能是binwalk的版本问题。

  1. binwalk 现在最新版本为V3.1.X，而 ubuntu22 上 apt install 安装的默认版本才V2.3.X，同事电脑上ubuntu18的binwalk版本才V2.1.X。
  2. 一个比较好用的固件解包网站 （之前总是能解出来一些本地解不出来的文件系统）上描述网站解包功能的实现时也只说了：“解包功能基于binwalk，收集了公开解密工具”。因此，猜测这个网站在固件解包方面没有做什么优化，只是单纯的binwalk版本比较高。

按照官方给的编译方法 完成编译，注意事项：
1、Ubuntu22以上
2、先执行 sudo apt autoremove binwalk 卸载之前使用apt命令安装的binwalk
3、编译前先安装 sudo apt-get install libbz2-dev 7zip ,如果在按教程编译过程中提示缺少xx库，根据提示下载对应的库
4、编译完成后binwalk二进制在/path/to/binwalk/target/release/binwalk下，需要软链接到/usr/bin目录下，方便全局使用，使用命令（需要写binwalk的绝对路径） sudo ln -sf /path/to/binwalk/target/release/binwalk /usr/bin/
